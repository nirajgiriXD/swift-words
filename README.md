# SwiftWords
**Read faster. Focus better. One word at a time.**

SwiftWords is a lightweight web application designed to help users read significantly faster by minimizing unnecessary eye movement.

Instead of displaying full paragraphs of text, SwiftWords presents content one word at a time at a controlled pace. This approach allows readers to focus on comprehension rather than visually scanning lines of text—one of the primary causes of slow reading.

By guiding the reader’s attention to a single focal point, SwiftWords improves reading speed, reduces visual fatigue, and enhances concentration. It is especially useful for long articles, study materials, and rapid information consumption.

## Features
- Word-by-word text display (RSVP-style reading)
- Adjustable options for reading speed (words per minute)
- Option to pause, and play words
- Support for various text formats (plain text, articles, etc.)
- Clean, distraction-free interface
